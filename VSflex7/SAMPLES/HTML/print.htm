Printing the Grid

This sample shows how you can print the VSFlexGrid using the built-in PrintGrid method or using the VSPrinter control.

The VSFlexGrid control includes a PrintGrid method that renders the grid on the printer. You have control over margins, orientation, and whether to display a printer selection dialog to the user. If the grid is large, the report may span several pages. If you need more sophisticated and flexible printed output, with previewing and the ability to create reports with several grids, text, tables, and other elements, then you can use the VSPrinter control (available separately from VideoSoft).
