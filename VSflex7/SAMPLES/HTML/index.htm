VSFlexGrid 7.0 HTML Samples
Index

The following samples demonstrate the use of VSFlexGrid in a web page. Note that the first three samples require you to set up an ODBC data source named NorthWind that is connected to the NorthWind database that ships with Visual Basic. The grids in these three samples will not contain any data unless you first create this data source.

Simple ADO Binding This sample shows how you can bind the VSFlexGrid control to ADO recordsets.

Hierarchical ADO Binding This sample shows how you can bind the VSFlexGrid control to a hierarchical (shaped) ADO recordset.

Binding to an RDS data source This sample shows how you can bind a VSFlexGrid control to an RDS (Remote Data Services) data source.

Binding to the Tabular Data Control This sample shows how you can bind a VSFlexGrid control to a Tabular Data Control (TDC).

Binding to an Array This sample shows how you can bind the VSFlexGrid to an array using VBScript.

Applying WallPaper This sample shows how you can apply a graphical background to the VSFlexGrid using the WallPaper and WallPaperAlignment properties.

Printing the Grid This sample shows how you can print the VSFlexGrid using the built-in PrintGrid method or using the VSPrinter control.
