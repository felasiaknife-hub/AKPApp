VSFlexGrid 7.0 HTML Samples
Simple ADO Binding

This sample shows how you can bind the VSFlexGrid control to ADO recordsets.

Note that this sample requires an ODBC data source named NorthWind that is connected to the NorthWind database that ships with Visual Basic. The grids below will not contain any data unless you create this data source. The sample creates ADODB connection and recordset objects, then connects the to the VSFlexGrid control using the grid's DataSource property.

The top grid is bound to a recordset opened in adLockOptimistic mode, so any changes made to the data on the grid are immediately save to the underlying database. The bottom grid is bound to a recordset opened in adLockBatchOptimistic mode, so changes made to the grid are not reflected on the underlying database until the user clicks the Update Database button.

Grid 1: CUSTOMERS
Changes made to the grid are immediately saved to the underlying database.

Grid 2: EMPLOYEES
Changes made to the grid can be applied to the database using the button or undone using the button.
