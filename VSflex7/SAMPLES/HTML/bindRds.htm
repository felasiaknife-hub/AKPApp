VSFlexGrid 7.0 HTML Samples
Binding to an RDS data source  

This sample shows how you can bind a VSFlexGrid control to an RDS (Remote Data Services) data source.

The sample creates an RDS.DataControl object and sets its CONNECT and SQL properties to display the 'Employees' table from the 'NorthWind' database. Then it creates a VSFlexGrid control and binds it to the data source.

You may edit the values by typing on the grid. When you are ready to commit the changes, click the "Submit Changes" button to write the new information to the underlying database. If you change your mind, click the "Cancel Changes" button to restore the original data from the database.
