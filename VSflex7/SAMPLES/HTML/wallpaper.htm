VSFlexGrid 7.0 HTML Samples
Applying WallPaper  

This sample shows how you can apply a graphical background to the VSFlexGrid using the WallPaper and WallPaperAlignment properties.

The sample loads pictures from graphics files using VBScript's LoadPicture function. The picture is then assigned to the grid's WallPaper property and the picture is displayed as a grid background. You can select the picture alignment to make it appear in different positions, stretched to fill the control, or tiled.

Notes:
1) The picture does not scroll with the grid contents.
2) The grid's BackColor is used to paint the background of cells while they are being edited, so you should assign the grid's BackColor property to a value that is similar to the picture's background.
3) The pictures used in this sample were "faded" using Microsoft's Image Composer so that they don't obscure the grid contents.
