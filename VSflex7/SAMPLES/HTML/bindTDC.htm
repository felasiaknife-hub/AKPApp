Binding to the Tabular Data Control (TDC)  

This sample shows how you can bind a VSFlexGrid control to a Tabular Data Control (TDC).

The Microsoft TDC ships with IE4. It lets you display data that is stored in a delimited text file. The data can optionally be filtered or sorted by the browser using the properties and method exposed by the control. The control exposes ADO data binding interfaces, so you can use it as a data source for the VSFlexGrid control.

The TDC is useful  only for displaying data. Edits made to the data are not reflected back to the underlying delimited text file. You can, however, save the modified data using the VSFlexGrid's SaveGrid method. 

The sample shows two grids. The top grid is bound to the TDC in the usual way. You can sort the data using the TDC's Sort property. You can also edit the grid, but the changes will not be reflected back into the underlying delimited text file.

The bottom grid is connected to the data in "unbound" mode. This means the data is read from the data source when the control loads, and then the connection is broken. You can sort this grid using the VSFlexGrid's built-in sorting. Click the column headers to sort the grid.
