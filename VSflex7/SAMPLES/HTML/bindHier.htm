Hierarchical ADO Binding

This sample shows how you can bind the VSFlexGrid control to a hierarchical (shaped) ADO recordset.

Note that this sample requires an ODBC data source named NorthWind that is connected to the NorthWind database that ships with Visual Basic. The grids below will not contain any data unless you create this data source. The sample creates ADODB connection and recordset objects, then connects the to the VSFlexGrid control using the grid's DataSource property.

The ADO connection is created using the MSDataShape provider, and the recordset Source statement contains a SHAPE SQL command that was created using the Visual Basic 6 Data Environment. The main recordset contains Customer records. Each Customer record has an "Orders" field that is a subordinate recordset. Each order record has a "Details" field that is a further subordinate recordset.

The top grid is bound to the Customers recordset. The bottom grids are bound to the Orders and Details recordsets. Note that as you navigate the Customers grid, the other grids remain synchronized and display the information for the currently selected customer and order.
