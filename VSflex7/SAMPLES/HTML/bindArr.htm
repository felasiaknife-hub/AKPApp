Binding to an Array

This sample shows how you can bind the VSFlexGrid to an array using VBScript.

When binding the grid to an array, you have the option of specifying which array dimensions map into the grid's rows and columns. By default, the first array dimension maps into grid columns, and the second maps into grid rows. This is the convention used by ADO when returning recordsets as automation arrays. This sample shows how to perform the binding using the default dimension mapping and how to perform a transposed mapping, where the first array dimension maps into grid rows and the second into grid columns. 

Notes:
1) The data you see on the grid comes from a VBSript array variable that is populated when the window loads.
2) The grid's dimensions are set automatically, based on the size of the array.
3) The grid is editable: changes made to the grid are automatically saved back into the array.

Bind using default mapping: the first array dimension maps into grid columns, the second into rows.
Bind using transposed mapping: the first array dimension maps into grid rows, the second into columns.
