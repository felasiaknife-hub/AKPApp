Selection
VSFlexGrid 7 VB Demo Project
------------------------------------------------------------------------


This project shows how you can use code to control extended selections
and scrolling in the FlexGrid control.


The Selection project demonstrates:

- How to use the BeforeRowColChange and BeforeSelChange events to 
  prevent the user from selecting a range with the mouse or keyboard.

- How to use the BeforeScroll and AfterScroll events to prevent the
  user from scrolling the grid while an action is being performed
  on the current cell or to keep the current cell always in view.
